## 🧠 NEUROMARKETING PRINCIPLE: GAP THEORY

**Gap Theory:** Create information gap → Build curiosity/tension → Release with answer

**Why it works:**
- Human brain seeks closure (Zeigarnik effect)
- Unresolved tension creates engagement
- "Aha!" moment when gap is filled = memorable

**Applied to homepage:**
1. "Why we exist" = Problem (creates gap)
2. [Visitor scrolls, wondering "how?"]
3. "Our solution" = Answer (releases tension)

## 🧠 PSYCHOLOGICAL PRINCIPLES APPLIED

### 1. Zeigarnik Effect
**Principle:** Unfinished tasks stay in memory better than completed ones

**Applied:**
- "Why we exist" ends without solution
- Brain seeks closure → scrolls to find answer
- "Our solution" completes the loop → memorable

---

### 2. Information Gap Theory (Loewenstein)
**Principle:** Gap between what we know and want to know drives curiosity

**Applied:**
- Know: "There's a problem with rural finance"
- Want to know: "How do they fix it?"
- Gap drives scroll to next section

---

### 3. Pattern Completion
**Principle:** Brain naturally seeks to complete patterns

**Applied:**
- "Why we exist" sets up pattern: Problem → ???
- "Our solution" completes pattern: Problem → Solution
- Completion creates satisfaction → positive association

---

### 4. Redundancy = Cognitive Tax
**Principle:** Repeated info feels like wasted time → disengagement

**Before:**
- Same message 2x → visitor feels time wasted
- Long intro + cards → visitor skips to cards

**After:**
- Each section adds new info → visitor feels progress
- Intro complements cards → visitor reads both
